# Headless Raspberry Pi setup

Use Raspberry Pi Imager to write Raspberry Pi OS Lite for a headless device. In the OS customisation screen, configure a hostname, user credentials, Wi-Fi, and either SSH or Raspberry Pi Connect before first boot. SSH and Connect are available on the first boot; VNC is not available on Raspberry Pi OS Lite.

Connect the boot media, power on the device, and reach it over the configured network using its hostname or IP address. Public-key authentication is preferable to password authentication for an internet-adjacent system.
